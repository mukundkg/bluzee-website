This ZIP is a small update package, NOT a complete standalone website.
It is based on Bluzee_v6_Complete.zip. Keep your existing repository files.

Cloudflare build command (exit 0) serves dist without rebuilding Python.

WINDOWS / GITHUB DESKTOP — STEP BY STEP
1. Download this ZIP. Right-click it and choose Extract All.
2. Open GitHub Desktop and select bluzee-website. Fetch/Pull origin first.
   If Desktop shows your own uncommitted edits, save them in a commit first
   and keep a copy before merging this update.
3. Choose Repository > Show in Explorer. Open the repository root: this is
   the folder already containing dist, content-source and build.py.
4. In the EXTRACTED update, select ALL contents (dist, content-source,
   media-update, Python files and this instruction file). Copy and paste
   them into that repository root. Merge the folders and choose
   'Replace the files in the destination' for the included files.
   DO NOT delete the existing dist folder. DO NOT put the ZIP itself, or a
   second nested update folder, inside dist. Existing PDFs/assets must stay.
5. Return to GitHub Desktop. Review Changes. Use the summary:
   Connect website media to Cloudflare R2
   Click Commit to main, then Push origin.
6. Cloudflare Pages should run the deployment for that commit. Wait for its
   successful completion. Keep these settings:
   Production branch: main | Framework: None | Build command: exit 0
   Build output directory: dist | Root directory: blank
7. Open https://bluzee-website.pages.dev/ and press Ctrl+F5. Test Events,
   Testimonials, ERP Experience Hub and the Professional Character page.
   Play each recording, check its title/content, seek within it, and close
   the player. Test the additional-photo and Volvo letter links too.
   Check the leadership portraits on About Us. Test on a phone as well.
